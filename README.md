# V1 活动页制作

当前版本：**v1.2.0**。

从用户提供的 KV 制作 1920px 运营静态活动页。先展示三套实际背景与轻量前景样张，用户选定后复用背景、完成一套正式前景和分层素材。

## v1.2.0 更新

- 优化三套样张制作：共用页面结构，先完成实际背景与轻量前景，选定后再精修一套完整素材。
- 保留组件质感，同时结合 KV 和整页层级控制细节；完善奖品展示形式与真实文字容量检查。
- 区分包围底框、图形衬托和实体承托，分别检查盲盒构图、透视与接触关系。
- 加强所选前景的边缘、材质与状态精修，校准有效画布及可见主体尺寸。
- 保护原 KV，背景复用所选样张；整理交付不触发背景重画。
- 正式图片按用途命名并平铺，去除业务占位文字、复用相同底图；制作档案单独保存。
- 按制作阶段读取规范，减少样张阶段的重复处理与提前导出。

## 安装与使用

将完整的 `v1-activity-page/` 文件夹放入所用 AI 客户端的技能目录，并按客户端方式加载。升级前备份自己的定制内容。

上传 KV 后输入：

```text
使用 $v1-activity-page，根据这张 KV 制作活动页。
保留默认的套餐购买、盲盒抽奖和获取更多抽奖机会模块，
先展示三套背景配轻量前景样张，等我选择后完成正式素材。
```

需要 KV、业务配置、图片生成、网页搜索、实际图片查看和浏览器预览能力。辅助脚本需要 Python 3.10+ 与 Pillow，跑马灯预览在浏览器中运行。

```sh
python -m pip install Pillow
```

## 支持内容

- 套餐购买、盲盒或跑马灯抽奖、抽奖任务、独立模块标题与装饰。
- 默认浮动活动规则入口；礼包、平铺活动规则和普通 Banner 按需启用。
- 整体衔接与按模块区分两种背景方式，沿用 KV 的视觉方向。
- PNG 默认 72 PPI；保留 V1 尺寸规则，不改为 V2 的双倍导出。

默认流程：确认配置 → 搜索并展示实际参考 → 三套样张 → 用户选择 → 单套精修 → 完整页面检查与交付。活动成品为静态展示，不包含真实登录、支付或抽奖服务。

## 交付内容

- **正式素材**：按用途命名的图片平铺在一个文件夹，卡片与按钮默认无业务文案，相同底图复用；实际不同状态分别保留。
- **整页预览**：1920px 完整页面图，放在正式素材目录旁。
- **制作档案**：离线页面、源文件、素材清单和检查记录，保留原有相对路径。

活动成品默认交付文件夹；此 Release ZIP 用于安装技能。

## 文件与工具

入口为 [SKILL.md](v1-activity-page/SKILL.md)，包含界面配置、6 份专题规范及 4 个辅助脚本。交付规则见 [素材交付](v1-activity-page/references/material-delivery.md)，尺寸和配置见 [布局与清单](v1-activity-page/references/v1-layout.md)。

| 脚本 | 用途 |
| --- | --- |
| `export_background_slices.py` | 根据清单从背景母图原像素导出切片 |
| `normalize_png_ppi.py` | 检查或规范化 PNG 分辨率元数据，保留像素及透明度 |
| `validate_output.py` | 检查制作档案中的页面、素材与清单 |
| `marquee-preview.js` | 跑马灯单格高亮轮转与暂停预览 |

在技能目录内运行 `python scripts/<脚本名>.py --help` 查看参数。完整页面校验在制作档案的页面根目录执行，不针对平铺图片目录运行；脚本通过仍需完成真实视觉检查。
