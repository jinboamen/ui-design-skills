# 工具接入与证据来源

当前正式流程保留远程 Figma MCP；本 Skill 不包含或自动安装本地桥接服务。官方本地 MCP 可提供其实际支持的辅助读取，但不能因同名工具存在就宣称具备远程的完整能力。工具可用性与模型品牌无关。

## 前置与能力核对

先查看当前客户端暴露的工具名称、参数 schema、权限与返回内容；不要编造参数或仅凭服务名称推定功能。已有可靠能力信息不重复探测；缺少关键证据时允许针对目标节点执行必要的只读核对。

当前环境确实提供并要求 Figma 前置技能时，在 get_design_context/use_figma 前加载相应技能并按真实 schema 传参。不要把某客户端专用的 skill name 参数、命名空间或工具发现方式强制套到其他客户端。浏览器工具同理，优先遵循当前环境的使用规范。

| 必须取得的证据 | 正式路径/边界 |
| --- | --- |
| 精确根节点与模块导航 | metadata 只用于 ID/层级/几何导航，不代替完整属性 |
| 静态结构、文字与样式 | get_design_context 加必要的完整节点属性；缩略图仅辅助识别 |
| Export/Slice、母版继承、实例映射 | 远程 use_figma 中的 Plugin API，包括 getMainComponentAsync、exportSettings、精确实际对象 |
| 正式素材 | 在实际 renderNode 上执行 exportAsync，规则见素材专题；不把截图或原始图片混成正式切图 |
| Prototype/Variant | 完整 reactions、组件集与 action 目标；静态上下文不构成反证 |
| Motion | 当前运行时可用的 motion context/Plugin API；不支持与未发现动画分开记录 |
| 独立设计基准 | 与候选导出不同来源的画布渲染或可追溯手动导出；核对节点、边界、尺寸、状态与 Alpha |
| 网页验收 | 实际浏览器截图、DOMRect、computed style、交互、控制台与构建 |

use_figma 是远程专属能力时，不可将其调用直接改名为桌面工具；本地缺少必要能力则标记对应项 unverified，继续不依赖它的工作，不能靠图层命名补充未经读取的属性。

## 正式导出与数据传输

导出配方和倍率只按素材规则生成，在精确实例/节点 exportAsync。不要用 download_assets 的默认格式/倍率参数替代这一正式导出流程；该工具返回的原图和预览也不得绕过素材准入。传输 Uint8Array 时使用工具支持的二进制、资源文件或 figma.base64Encode；大批资产分批处理，避免将所有图片 Base64 一次塞进模型上下文。

临时下载地址及时保存到项目外暂存区。通过验证后才进入项目；详细清单可保存到临时文件按模块读取，返回摘要、文件位置、节点数量和缺失项。截断响应不是完整扫描。

## 基准截图

先确定 implementationRoot。根据实际 schema 使用尺寸和内容边界参数：如果远程 get_screenshot 提供 contentsOnly/maxDimension，应显式选择仅目标内容与足以覆盖目标物理尺寸的上限。65536 只是某些实现可用的参数值，不是跨客户端保证。取回后解码检查真实像素尺寸，不能把调用成功或返回的尺寸文字当成验证。

对齐 absoluteBoundingBox（布局）与 absoluteRenderBounds（阴影等出血），记录截图原点偏移。基准被缩图时重新获取合格分辨率；放大缩略图不能恢复精度。Page 同级浮层单独取补充证据，不把含画布底色的补充图混作透明或整图像素差基准。

素材独立双源与网页基准分别取证。预期透明素材的准入基准必须具有匹配尺寸与真实 Alpha；不透明编辑器截图不能作为 Alpha 基准，截图也不得冒充正式导出。候选导出重复一遍不能变成独立来源。

## 已有桥接的使用边界

仅当用户明确要求启用已有 Figma 证据桥接工具 时读取 [桥接适配](asset-bridge.md)。环境存在工具、远程返回不完整或历史使用过，都不构成自动连接授权。当前没有桥接运行时就明确记录，不从文档里的工具名推断已安装。本规则不要求开发插件，也不把桥接当作默认回退。

## 不可用与失败

权限不足、参数不支持、扫描截断、目标缺失、运行时不支持 Motion、没有独立基准、没有真实浏览器或依赖不可用均记录具体证据缺口；不把缺口当零结果。源码样式可辅助诊断，不能替代缺失的运行时计算样式或实际交互验收。

透明素材脚本执行前，若环境提供依赖解析工具优先使用；否则定位并核验本机 Python 与 Pillow（解释器路径及实际 import），不要假设 PATH 中 python 可用。找不到时保持 unverified，不手动复制绕过闸门。
