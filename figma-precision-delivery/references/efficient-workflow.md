# 执行等级与增量流程

## 两种执行等级

普通“精准还原、实现、继续修正”使用默认增量精准模式；用户明确要求严格 1:1 认证、逐节点审计、完整验收证据或上线前最终认证时使用严格模式。

| 要求 | 默认增量精准 | 严格 1:1 认证 |
| --- | --- | --- |
| 可见节点覆盖、所有唯一素材双源、最终整页及全部一级模块像素差 | 全部执行 | 全部执行 |
| 相同组件/交互签名 | 完整分析一次，其余实例仍逐个检查内容、尺寸、边界、当前状态、映射、触发可达性 | 实现可复用，逐实例保留独立完整证据 |
| 完全相同素材候选 | 按素材规则的完整指纹复用通过结果；保留各候选来源与引用 | 可共用文件，但各候选独立认证记录 |
| 视觉状态 | 每个唯一签名验证默认态及全部可达状态、每一种唯一转换；其余同签名实例仍逐个检查 | 每个实际实例的默认态、全部可达状态及转换都有独立截图与证据 |
| 多视口 | 按视觉规则的触发条件 | 当前支持视口矩阵的完整最新证据 |
| 对外表述 | 全部通过才可称“默认增量精准模式通过”或“精准实现完成” | 全部通过才可称“严格 1:1 认证通过” |

不同职业、模型或接入方式不改变验收标准。设计师使用和开发使用不是两个质量等级。

## 设计快照

首次锁定 fileKey、linkRootId、implementationRootId、根 Export 意图，并记录 designEvidenceRevision（文件/节点版本、更新时间或可验证等价标识）、各证据通道的来源/时间/范围/哈希。版本标识不存在时记录可复验的节点内容哈希；无法证明有效性时重新读取，不能仅凭缓存文件存在复用。

快照与验收证据只存项目外的任务临时目录，不提交。缓存键包含文件、真实交付根、设计版本、节点树/Export/Slice/组件/Prototype/Motion 分类哈希以及受影响源码或构建哈希。

先读取根意图与 Export/Slice，确定原子节点，再读取剩余视觉数据。Prototype 与 Motion 分别采集，不用静态结果替代；独立通道允许批量或并行读取。只重试失败或截断的通道。原子后代可保留覆盖映射所需的最小 ID/可见性/结构索引和交互必要数据，不再获取或使用其独立视觉样式、参考代码或素材。

## 签名与复用

- 组件：当前主组件/组件集、Variant、实例覆盖、可见文字与图片等实际内容、尺寸与响应式约束、根/子层 Export、transition/duration/easing。
- 交互：起始组件/Variant、trigger、actions 顺序、目标节点/Variant、transition/duration/easing、条件与变量分支。
- 素材：完整指纹与复用门槛只按 [素材规则](asset-extraction.md) 执行，不能仅凭组件 ID、名称或输出文件相同合并来源。

组件与交互签名同时一致，才可使用代表实例；任何字段不同即拆分。最终整页和所属模块仍覆盖所有实例的实际渲染。完整读取与节点覆盖分母不得因签名合并减少。

## 失效矩阵

| 变化 | 废弃并复验 | 可保留 |
| --- | --- | --- |
| 局部文案、颜色、图标 | 当前模块截图/样式/像素差 | 无关模块与设计证据 |
| 素材或 Export 设置 | 该素材验证、引用模块和相关状态 | 无关素材 |
| 交互/Variant | 相关签名、起止状态、过程、素材与行为证据 | 无关交互 |
| 模块布局、字体、裁切 | 当前模块几何/间距/截图及相邻边界 | 无级联影响的模块 |
| 根布局、全局字体/CSS、媒体查询 | 整页、相关模块、额外视口 | 未变的 Figma 源证据和素材验证 |
| Figma 内容、版本或交付根 | 受影响源快照及依赖证据 | 能证明无依赖且哈希一致的结果 |

不能确定影响范围时扩大到共同祖先；不能为节省调用沿用冲突或过期证据。

## 实现与收敛

1. 项目约束、真实 DOM、模块顺序。
2. 几何、布局、裁切与间距。
3. 字体、逐段文字、颜色与效果。
4. 正式素材：通过准入后入库与引用。
5. Prototype、状态与动效。
6. 受影响模块及状态局部复验。
7. 页面稳定后采集一次最新整页、全部一级模块、所需视口和全部最终检查。此后再修改则按失效矩阵重采，不得把“一次”解释为禁止重验。

连续修正不收敛时，先检查来源、资源、环境、父级布局，再处理局部数值。每个组件连续 5 轮仍失败时做一次根因复盘并报告阻断；有明确可修复原因则继续修正。轮次不是完成门槛，不允许到上限后放行；只有确需用户决策或外部能力时停止依赖部分，其他独立工作继续。

所有具体属性、数值阈值、完成条件和报告字段以 [视觉验收](visual-fidelity.md)、[素材准入](asset-extraction.md)、[交互保真](interaction-fidelity.md) 各自专题为准，不在本文件重复维护。
