# 已有 Figma 证据桥接适配（非默认）

只在用户明确要求启用已有 Figma 证据桥接工具时使用。此文件仅说明通用能力要求，不包含桥接实现，不证明环境已安装，也不要求创建新插件。默认接入规则见 [工具接入](tool-access.md)。

## 唯一职责

桥接只补充设计侧证据：文档与选区、Export/Slice、母版与实际实例映射、视觉属性与文本片段、Prototype/Variant/目标节点及 Motion。输出不构成网页验收。数据遵循同一 [素材规则](asset-extraction.md)、[交互规则](interaction-fidelity.md) 与 [视觉规则](visual-fidelity.md)。

## 已安装工具的适配顺序

1. 按当前客户端真实暴露的工具与参数核对连接状态、权限、目标文件和会话；不假定任何特定工具名或私有协议存在。
2. 锁定真实交付根，不按名称猜测或将整个 Page 当成交付根。
3. 按 [增量流程](efficient-workflow.md) 校验快照、版本与分类哈希，分别取得素材、交互和动效证据。
4. 扫描视觉属性并保留完整节点覆盖索引；截断或无法证明覆盖的结果标记为 unverified。
5. 在实际页面节点导出候选，只写项目外暂存区；每份唯一正式输出均执行独立双源验证。
6. 预期透明 PNG 来源必须由 scripts/transparent_asset_gate.py 完成准入与原子入库，不以桥接导出结果绕过脚本；其他格式也须验证后才能进入项目。
7. 最终仍执行真实浏览器验收；动效不支持、独立基准缺失、导出与渲染冲突、根不确定或协议不匹配时，报告相应失败或未验证项。

独立基准不能复用候选导出或同一次导出自证。编辑器画布或手动导出只有在节点、设置、尺寸、边界、状态与所需 Alpha 均匹配时，才可作为对应基准。无法取得合格基准时停止正式素材准入。
