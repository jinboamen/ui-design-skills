## Figma 最终设计稿的全局规范

凡使用 AI 在 Figma 中制作或修改设计稿，以下五项均为默认制作与验收要求，无需用户重复提醒，适用于通过任何技能或 Figma 写入工具完成的本轮工作。

1. 图片、logo 和 icon 保持原始比例，图片按用途等比适应或裁切。同组 UI icon 的描边视觉宽度与粗细统一，在最终显示尺寸以及画板宽度、状态变化后实际查看。
2. 创建组件前检索并复用已有母版。文案、显隐和替换内容用对应属性表达，仅建立实际需要的状态组合。核查重复和冗余组件、变体，迁移并验证受影响实例后再清理本轮范围内的冗余节点。
3. 主要内容使用精准的 Auto Layout 与响应式约束。拉宽画板时，应延伸的内容使用 Fill container，同级等分区域等宽分配，达到最大宽度后居中。每层 Frame 应有明确的布局、对齐、裁切、滚动、定位或组件边界作用。实际调整同一画板到较窄、基准和较宽尺寸验证，随后还原。
4. 界面文字严格依据原型、需求或原始内容。仅在用户明确授权的范围补充或修改文案。缺失内容在对话中说明，界面中禁止擅自新增文案、提示、说明、标注、占位文字或数据。临时测试内容在交付前还原。
5. 逐项检查页面、卡片、弹窗、按钮及其他内容容器的上、下、左、右 Padding 与实际可见留白，在尺寸、长文案、显隐和状态变化后复查。修正意外贴边后复验，通栏背景、满版图片等按明确设计依据处理。

制作或修改原生可编辑的 Figma 最终设计稿时，必须先读取并遵循已安装的 `ai-figma-design-workflow/SKILL.md`，再调用 Figma 写入工具。无需用户点名该技能。按任务类型执行其中的研究、样张确认或直接制作、组件复用与验收要求，局部修正按本轮授权范围推进。新视觉设计的参考研究按该技能执行。只读查看或导出按用户当次任务执行。

五项检查覆盖本轮交付区域及其使用的组件和状态。发现问题应修正并复验，无法验证的部分如实说明。技能暂不可用时，仍须遵循以上五项规范，并说明完整工作流的缺口。
