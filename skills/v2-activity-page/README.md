# V2 活动生成技能

基于主视觉 KV 和目标活动后台规格，制作 PC 活动页设计样张与可上传素材。支持单列、双列和逐行混排，按 1920px 设计基准制作，选定方案后交付一套 2× 位图素材。

## 安装与调用

```sh
npx skills add jinboamen/ui-design-skills --skill v2-activity-page
```

上传 KV，提供可访问的目标页面、后台规格或已确认的尺寸，然后输入：

```text
使用 $v2-activity-page，根据这张 KV 制作活动页。
先确认模块、排列、头图高度和背景方式，展示三套样张，等我选定后交付正式素材。
```

## 工作流程

1. 分析 KV，逐项确认缺失配置，核实实际后台尺寸与排列能力。
2. 搜索并实际查看相容的设计参考，按 KV 主题选择方向，不限定游戏题材。
3. 制作三套完整样张：背景达到最终设计状态，前景已具备功能层级和设计细节；明确说明选定后还会精修前景。
4. 用户选定一套后保留认可的完整背景，在既定布局内完善前景材质、边缘与局部细节，不以放大图片代替精修。
5. 按实际上传区域切图并合成验证；最终素材去除占位文案、相同素材去重，集中放入一个素材文件夹，另附整页预览。

单个套餐无选中态；多个套餐提供默认和选中两态，样张仅选中一个。二维码背景独立交付，不计入套餐数量。运行与交付细则见 [SKILL.md](SKILL.md)。

## 公开版范围

公开版保留规则、通用结构预设、辅助脚本与测试，已移除私人 Figma 链接、活动地址、后台测量记录、项目截图及本机路径。文档中的数值属于可核实的预设，不能当成其他后台的实测结果；示例 backend profile 只是离线测试夹具，不代表已接入实际后台。

执行需要图片生成与编辑、搜索与看图能力；涉及目标后台时需要用户提供相应规格或访问权限。本技能不包含真实登录、支付、抽奖业务，也不修改生产后台。

## 辅助脚本

Python 3.10+，图像检查依赖 Pillow：

```sh
python -m pip install Pillow
python -m unittest discover -s scripts -p "test_*.py"
```

脚本用于布局约束、素材规格、预览合成和切图检查。测试通过不等于视觉设计合格，也不证明目标后台的业务或上传流程可用；仍需实际查看整页、接缝、文字、状态及正式素材。
