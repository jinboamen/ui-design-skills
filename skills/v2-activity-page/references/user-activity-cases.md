# 视觉组织方法

公开版仅提供通用方法，不附带私人活动截图。需实际查看本轮相容参考；从当前KV选择方法，不照搬人物、品牌、奖品、价格和文案。截图不能证明后台支持自由定位或动态状态。

| 方法 | 可借鉴范围 |
| --- | --- |
| 开放构图 | 主体连接区域，留白、标题及奖品分组建立层级，不给每个模块分别套大框 |
| 章节分区 | 跨整行统一组织分区，保持强调色体系和清楚的购买行动 |
| 曲线连接 | 曲线跨区连接，套餐面板、抽奖承托与任务条按功能变化 |
| 主题材质 | 依KV选择纸张、金属或其他相容材质，克制使用纹理与分隔，不固定成任何题材模板 |

## 选用与验收

先区分当前后台行列与视觉分区，可以整页贯通、按行、按模块或组合组织；用户选择明显分区也不代表四块四种颜色。有意的色面、分隔线、曲线和斜切均可，跨界轮廓自然连接，不能在切图时意外截断。构图在共同母图中完成，模块换位或行高变化后重校受影响关系。

底板、外框和面板由内容需要决定，允许开放构图或局部承托。盲盒底板无需用户取消，使用包围框才检查完整包裹与定位，实体脚下台面另看透视与接触。标题共享字形、颜色角色、边缘与主题语言，可按内容采用不同层级及底条，不把统一做成所有标题完全相同。

写实或三维主体与平面控件可以协调共存；纸张、胶带、硬边或圆角等只在KV和相容参考支持时采用，不自动叠加为下一次固定模板。容器外形可变，但主要可见面上的完整问号和下方圆点必须保留并在真实大小下可辨。

奖品与容器、标题、按钮一同规划，保留真实数量、完整名称和识别度；允许的错落、旋转、局部叠压不得遮住关键信息或操作，不靠扩大盒体挤小奖品。先核实后台实际可调整的范围，不能凭截图增加自由定位能力或把所有奖品合成到不适用的上传位。

单套餐只用普通态；多个套餐的双态及任务各态需在主题内清楚区分、切换位置稳定。案例中出现的多个样式或状态不直接推导为多个套餐或同时显示的按钮，正式页面呈现本次实际状态。

这些方法补充已有的本轮搜索流程；除用户明确不搜索外，仍需搜索并实际查看、展示本轮相容参考。A／B／C先用1920px完整设计预览表达整体差异，选定后仅精做一套2倍高清背景和素材，不新增长期默认玩法或新的确认问题。
