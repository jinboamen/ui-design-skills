# 清楚的素材交付

## 唯一且平铺的成品入口

所有最终图片统一平铺在一个“正式素材”文件夹中，不按模块再建头图、套餐、抽奖、任务等子文件夹。用文件名区分用途，例如“头图背景.png”“套餐区域背景.png”“套餐卡片-默认.png”“套餐卡片-选中.png”“任务条底图.png”“任务按钮-可用.png”。另附一份一屏内的“先看这里.txt”。

整页1920px预览放在正式素材文件夹旁边，注明只看效果。原KV、母图、源文件、代码、样张历史、清单及验收记录保留在独立制作档案；只有一个正式素材入口，不再并列输出另一套最终／高清／上传包，不默认生成ZIP。

## 无字与去重

- 正式素材默认交付可自行换文案的无字底图。不烘焙“待配置”“套餐1”“任务条件”“奖品1”、示意数字／价格、按钮业务文字或奖品位置的问号占位。预览可独立叠加示意文字，不能将其合入最终底图。底图文件名不再沿用任务1、任务2、奖品1等重复占位编号。
- 套餐卡主体保留连续的干净文案空间，只保留底色／克制材质、外框、必要状态及购买按钮区域；不包含宝箱、商品插图、主题徽标、权益图标、固定权益条、价格框及预制信息小格。预览文字与卡片底图分开，按钮底图仍按默认无字导出。
- 原KV已有文字和标志不得动；用户确认的独立模块标题继续按设计交付；盲盒本体的问号是必需主题设计，必须保留。去占位不等于把这些内容全部擦掉。
- 同一底图被多个套餐、任务、奖品或按钮复用时只导出一份，以用途命名。仅文案不同的可用／待领取按钮用同一张无字按钮底图，不分别复制；真实外观不同的可用／禁用、套餐默认／选中等必要状态分别保留。不能把同尺寸但图形不同的素材误删为重复。
- 任务条主体相同时交付一张通用底图；如仅图标不同，将实际不同的图标独立保留、同一条底图共用，不整条复制。没有设计差异时不为满足配置实例数量人为制造重复图片。
- 盲盒环境照明、衬光、投射、接触阴影及地面反射已经合入最终背景PNG；盒体另交透明PNG。制作源可保留环境分层，成品不把这些必要效果拆成额外素材让用户自行拼，也不交一张与正式盒体无关的通用底景。
- 背景切片按实际位置保留，不因色调相近而合并；独立标题、必要状态、默认启用且仅本次明确取消时省略的二维码背景和按需装饰不因精简遗漏。二维码背景保持简洁，不含二维码或业务文字。
- 只有用户明确要求含真实文案的直传成品时才将已确认真实文案合入图片，仍不生成“待配置”文字。无字素材不宣称后台会自动补字，上传映射未核实时明确说明用途，不编造上传栏位。

## 大转盘独立切图

启用大转盘时按[转盘分层](module-options.md#大转盘切图分层)交付“转盘盘面.png”和“转盘指针与抽奖按钮.png”。后者为一张固定组合透明PNG；前者旋转且不含指针／按钮，模块背景也不重复烘焙这些固定控件。保持实际共同定位和2倍比例，按钮业务文字仍默认不烘焙。不能为去重或精简目录将两层合并，也不把固定组合拆成指针、按钮两个成品。分层源与映射放制作档案，最终图片仍平铺在唯一正式素材目录。

## 整理与验证

保持2倍像素、72PPI及原有图形、纹理、颜色和透明度。优先复用已完成正式精修且验收通过的无字PNG；样张示意件或尚欠完成度的粗略素材先按[设计还原与精修](selected-design-reproduction.md#保留方向与补足完成度)制作，不能因已有文件或去重规则直接跳过精修；需去字或分离图标时从可编辑分层源关闭文字层／拆分图层后导出，不以涂色、模糊或大块擦除损坏设计细节。不为去重、改名或改目录重新生图。

完整制作档案仍保留原角色、实例及状态记录；多个角色可映射到同一张共用交付文件。导出映射和哈希记录放在制作档案，不复制技术清单进用户成品目录。完整validate_output.py在制作档案运行，不在纯图片交付目录运行；针对本次去字／拆分检查文字层已关闭、必要设计仍在、尺寸与透明度正确、交付无重复和多余子文件夹即可，不重复整轮最终制作。

整理历史包时保留原含字版本在制作档案中，不破坏工作源及原预览引用。新无字导出另记录真实来源，不能伪称与含字源文件哈希相同；直接复制的素材核对哈希相同。最终回复直接链接唯一正式素材目录，简短说明无字、去重、平铺和必要的内容缺口。

## 所有素材的有效画布与左右贴边

本规则适用于所有生成的独立素材，从样张组件到正式2倍导出，不仅是任务条。用户明确要求：允许异形切角，但元素主体整体的左、右外沿必须分别到达实际画布左、右边界；两侧不得再有整条无用透明空白或人为安全边距。画布像素正确而主体内缩仍是不合格。允许切角处局部透明，不要求每一行都满宽；不能用一个尖角、孤立装饰、低透明光晕或补色像素触边来掩盖主要底板偏小。

这里的贴边针对素材外部边界，不删除卡片内部排版留白、二维码净区、文字安全区或主体真实孔洞。模块之间的间距交给页面布局，不烘焙进单件图片左右两侧。上下同样清除无用空边并用足实际槽位；自然比例、正确字形和完整轮廓不可因填满而拉伸或裁坏。

| 素材范围 | 制作与检查 |
| --- | --- |
| 套餐卡、任务条、奖品底卡、礼包卡、翻牌正反面、积分卡等面板 | 主要底板的左右外沿到画布边界，切角与边缘工艺局部透明可保留。底板内部仍完整承托真实文案、图片和操作区；不靠厚装饰框占满、把有效区域挤小。 |
| 购买、抽奖、任务、积分兑换等按钮及各状态，活动规则／中奖记录入口 | 按钮主体左右贴边，不在PNG中加入点击区或页面间距。保持实际控件尺寸，文字另排；不拉伸带字成图。 |
| 二维码背景、弹窗底图 | 实际背景面板用足规定画布，左右无额外空边；保留内部码区与内容净空，不因贴边增加装饰、二维码或示意文字。 |
| 盲盒本体、奖品实图、图标、独立装饰 | 按有意义的可见主体定左右外沿，去掉无内容透明外围；等比适配，不能把物件压扁或横向拉宽。场景地面、投射和环境光继续归背景，不用它们撑宽主体PNG。 |
| 独立模块标题 | 完整标题设计组包括正确字形、字效及既有底板／线条／角标，设计组左右贴边；同级字面高度保持一致。没有固定宽度时使用内容实际宽度，不能给短标题加空白凑长标题宽度，也不能拉长文字；后台固定槽位则在真实槽位内调整同一套底板／配套图形，不删底板、不改变字形。 贴边针对完整设计组，不要求文字本体铺满宽度；不得为贴边拉宽／压扁文字。按[正确字形与正式输出](art-direction.md#正确字形与正式输出)回到排版源适配并等比导出。 |
| 整页及模块背景、Banner／头图 | 背景覆盖整个切图矩形，不留透明条或单独补色条；沿共同母图原像素切片，左右无缝。贴边不要求KV人物／文字铺满或局限于左侧半栏：左上头图允许按[跨列主视觉](v2-layout.md#左上头图跨列构图与切片)进入右侧，重要内容不被套餐前景遮挡。原KV内部不裁切、不变形；比例缺口按原规则在原图外AI延展。 |

同一组件的默认／选中／禁用等状态共用画布、主体位置及左右外沿，不能各自裁边后出现不同尺寸或切换跳动。装饰或发光改变时仍以主体边界对齐，必要细节在规定范围内完整设计，不靠增加一圈透明画布容纳。

检查分两层：先看实际PNG的透明范围与可见主体左右边界，发现整条空边就修；再看主要底板和内部内容承托，避免仅外围装饰触边。纯色或不透明底图也必须看主体是否内缩，不能只查alpha。利用现有component_comparison／export_fidelity记录检查结果，不新增一轮三套高清或单独审批。

修复在制作源中调整主体与外框的几何范围，保持规定导出像素、原设计细节、颜色和正确比例。可变画布按内容紧边导出；固定画布则在源中按目标比例调整无字底板或局部扩展，并回填真实文字／按钮确认。禁止只裁掉空边后非等比放大整张位图、裁掉有效细节、用纯色边条或假透明像素凑贴边；若天然物件比例与固定宽高无法同时满足，明确记录冲突，不悄悄变形或声称已达标。

## 任务条底图的实际覆盖范围

任务条遵守上文所有素材左右贴边要求，需同时满足画布尺寸、可见主体外沿、内部文字及按钮承托区三项，不能只检查PNG宽高。以已确认采用600×120显示槽位为例，2倍导出1200×240；设计时主体直接在该槽位中构建，不在图内再加一圈外边距，使整个有效底板缩进。任务条之间的页面间距由布局承担，不烘焙成每张图片的透明留边。

外围装饰、尖角或光晕触到画布边缘不代表主体已经撑满。检查主要底板的实际覆盖范围，并将真实前台标题、说明文字及按钮按固定坐标叠加：文字和按钮应完整落在预定承托区内，不能因为厚边框、大切角或内缩底板而跑到透明区、装饰上或底板外。外围结构和纹理应让出必要阅读及操作空间，不缩小前台文字、按钮或移动真实布局来迁就图片。

自然切角、异形轮廓与必要抗锯齿允许局部透明；不要求所有像素不透明，也不将形状强行改成矩形。消除的是无设计用途的外围空边与主体内缩。预览时用明显对比色底检查透明范围，但检查色不得导入交付PNG；截图中的红色不自动视为实际素材底色。

发现问题时优先修改分层源中底板和边框的几何范围，在相同最终尺寸重新导出，保留原纹理、轮廓及主题细节。若只有位图且比例不匹配，需要局部扩展／补齐底板，不能裁去空边后把整张图非等比拉伸，也不能加纯色外围使像素检测看似铺满。修正后按实际显示大小回填一次，检查主体覆盖、文字和按钮承托及完整边缘；无需重新生成其它模块或三套样张。
