# 盲盒次数与概率信息行

本节提供盲盒信息行的固定布局预设，不附带私人活动链接或测量记录。使用前核实本次前台符合该预设；确认后字号和位置不随主题变化，只有真实次数及文字颜色变化。

## 固定的1倍设计参数

| 项目 | 固定要求 |
| --- | --- |
| 排列 | 同一行，次数在左、概率在右，不换行 |
| 字号／行高 | 20px／30px |
| 字重与字形 | 400，常规字形；沿用线上全局系统字体，不换活动艺术字 |
| 字距、倾斜 | normal、normal，不做额外拉伸／字形变换 |
| 两项间距 | 概率文本左边界与次数文本右边界相隔110px |
| 按钮下间距 | 信息行顶部距抽奖按钮实际显示矩形底边40px |
| 对齐 | 两项同排对齐，整组水平居中于抽奖按钮及盲盒模块 |
| 概率入口 | 保留前导“*”和下划线，文字“奖品概率”完整 |
| 可变项 | 真实次数及前台配置的文字颜色；排版不随活动风格重做 |

预设按钮宽230、高度随上传原图比例自动确定；40px从实际按钮底边算，不从固定60高画布或按钮内文字算。信息行总宽由次数文字自然宽度＋110＋概率文字自然宽度决定，不固定为某个总宽，也不从截图缩放比例猜尺寸。数字位数／系统字体正常渲染差异可能改变左右端点，整组居中与110间距保持。背景同行取较高后也不将此信息行独立下移或拉伸来填空。

## 复用方式

这是前台普通文字与文字入口，分别保留data-role=draw-count和data-role=prize-probability，并在同一个data-role=blind-footer容器内按左→右顺序排列。容器位于data-module=lottery的盲盒模块中，概率入口不是概率说明弹窗图片，也不是中奖记录按钮。只保留这两项，不能增加中奖记录、竖线、图标、花边、共同底板或截图标注红框，不把文字烘焙进PNG。

以下适用于与线上相同的根字号体系（1920时1rem=16px）；其它实现用等效设计尺寸并按整页缩放，不能重复缩放或单独让文字保持屏幕20px：

```css
[data-role="blind-footer"] {
  display: flex;
  align-items: center;
  align-self: center;
  width: max-content;
  margin-top: 2.5rem;
  padding: 0;
  font-family: inherit;
  font-size: 1.25rem;
  line-height: 1.5;
  font-weight: 400;
  font-style: normal;
  letter-spacing: normal;
  white-space: nowrap;
  color: var(--lottery-info-color, #fff);
}
[data-role="blind-footer"] [data-role="prize-probability"] {
  margin-left: 6.875rem;
  color: inherit;
  text-decoration: underline;
  text-decoration-color: currentColor;
}
```

该容器紧接实际盲盒／按钮组，其上间距只设置一次。沿用线上全局字体栈，不因示例font-family:inherit而从艺术标题容器继承特殊字体。所有主题中的字号、行高、字重和间距保持，颜色按活动后台当前配置；次数为真实业务数据，未知写明确待配置，不复制参考中的0作为正式数据。

## 两阶段检查

样张直接按该固定信息行表现，不生成三种排法让用户选；不对这行单独生图或做字效。正式阶段在已有1920浏览器回填中测一次字体、行高、两项间距、按钮下间距与组中心，复用现有整页截图检查，不增加额外审批或专项图片包。较小／较大PC视口随整页等比缩放，结构及顺序不变。

本节只规定盲盒信息行，不改动概率弹窗本身的自适应高度，不将固定数值直接推广到翻牌、跑马灯或移动端。全局V1不作修改；本技能中的历史单列说明不能把盲盒次数移入任务信息行。结构校验可检查同组、顺序及额外文字，实际CSS计算值仍须浏览器查看，不能靠HTML标记或文档数字冒充已验收。
