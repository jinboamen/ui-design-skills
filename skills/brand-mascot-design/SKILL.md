# 原创品牌 IP 设计

按用户要的阶段工作。造型提案要有能比较的形态，审稿要指出具体改法，三维稿要证明同一个角色的体块与表面在不同角度都成立。按项目要求使用设计参考和确认节点。借鉴案例中的决策方法，在本项目的原型和品牌语境中重做造型。

新设计和结构改稿先读 [创意、体型与表情的推导](references/design-development.md)。只做已批准形象的三维转译时，直接进入标准像和 [三维造型与材质](references/3d-direction.md)。

系列、换装、品牌全案或周边交付时，另读 [系列与品牌应用](references/applications.md)。

## 先定观众要读懂什么

从需求里选定本轮最重要的一件事，把它写成观众看图后能回答的问题。不同任务用不同依据选稿。

| 需求 | 选稿时先看什么 |
| --- | --- |
| 特定实物、动植物或产品拟人 | 观众需要认到哪一级？先找容易混淆的近邻，并指出真正有区分力的比例、部件关系、色块或典型使用状态。若用户强调一眼认出，草图中保留一款优先表达原型的方案以供比较。 |
| 人物身份、职业或文化主题 | 角色在做哪件有身份特征的事？看衣着、身体姿态、持物方式与使用情境能否相互印证。必要时保留承担身份信息的道具。 |
| 品牌服务、价值观或虚构概念 | 把抽象词换成角色会为谁做什么。在一个具体情境里画出它的选择与后果。有既定品牌资产时，提取允许使用的造型或色彩线索。 |
| 系列或已有角色延展 | 哪些线索让人认出同一家族，哪些线索让人分清成员？优先保留已定稿角色的结构和授权改动范围。 |

据此选工作量。比较新创意时，候选之间应改变与首要目标有关的设计决定。局部改色、表情或材质委托可直接沿用已定结构。按用户约定的来源使用参考，并把个案里的手脚数量、材质和画风留在对应项目内。

## 从原型找到角色本身的特点

1. **先定它代表什么、给人什么感觉、常做什么。** 从产品特征、制作或使用动作、工具、场景、职业和品牌主张里找素材。把创意说成一句可以画出来的话，能说明为何取这两个元素、哪一处形体因此改变。原型的识别点、角色自己的记忆点、能反复演出的动作，可来自同一处结构。
2. **把造型分成面、线、点。** 大面优先保留支撑身份的外轮廓和主要块面，合并重复的小转折。线表达连接、遮挡或分区。点留给表情或个别有识别作用的细节。若一个小特征决定身份，可以放大它并预留轮廓位置。有明确原型时，对照原型图和草图标清保留、合并、夸张的位置。抽象概念可从关键动作的姿态起稿。
3. **先改大形，再改脸。** 用同尺寸无色小草图比较不同构造，实质上改变头身关系、轮廓节奏、重心或结合方式。先排一个主块、较小的副块和少量细节，让视觉焦点集中。判断头身一体、分体和肢体数量是否合适。选一套主导的几何语言，使头、躯干和四肢的圆角、转折与倾向有共同逻辑。允许用一处反差平衡性格。分别遮住脸和道具，确认剪影和姿态还能表达性格。
4. **让记忆点兼有结构或行为用途。** 从外形、身份或习惯里选择能影响角色动作的特征。结合第二元素时，写清谁负责大形、哪一处发生改变。按识别目标选择检查方法。剪影看姿态和比例，去字彩图看品类或品牌线索，连续动作看性格和意图。只剩「物体加四肢和通用笑脸」时，回到轮廓、比例和特征结合处改稿。

## 从线稿定到标准像

- 保留至少一张能看清结构的中性姿势。写清主块厚度、最宽和最窄的位置、四肢接点、前后遮挡和眼嘴贴着哪个面。脸可以用眼形、眼距、上下位置或姿态给出专属表情。关掉颜色检查剪影，打开颜色检查视觉重点。
- 给配色分配角色。把角色压成三档明度的大块，检查脸与相邻体块是否粘连、强调色是否散成重复小点，再分配主色、协调色和强调色。颜色不合适时先恢复固有色，再观察明度、饱和度、局部冷暖和面积。需要改动多个方向时，每次对比一个主要变量。
- 用户需要三维效果时，读取 [三维造型与材质](references/3d-direction.md)。先做固定灰模或单色体块，再决定材质和灯光。平面转三维之前把原先用线表现的细节明确为体块、凹槽、接缝或贴面图案。明确不同视角该看见和该被挡住的结构。

## 延展和交付

- 先构思角色具体做什么。从原型和性格推导一个标志动作，画清发力方向、支撑脚、与道具接触的位置，检查双侧发力是否有必要完全对称。换装时按角色结构改附件的开口、尺寸和连接，清理上一款遗留结构。换角度或表情后，把变化与标准像逐项对照。
- 使用 AI 辅助时，以原型、线稿或已确认标准像明确各参考的角色。给每轮单独写清固定约束与改动内容，先做主视图样张和必要的有风险视角，检查后再扩展动作组和应用。微小瑕疵可局部修整。关键部件位置或体块变形，回到结构稿或重做该视角。
- 商业延展先画清画面的大小关系，再丰富场景。做产品样机时，按单个载体分别控制比例、材质与图案位置，再放到一起检查。需要动效时，先决定是固定镜头的角色微动，还是镜头参与叙事。微动看主体一致性和轮廓分离，镜头段落检查每一次位移、景别和转场是否有画面作用。
- 按实际载体检查最小尺寸、裁切和色彩。头像看关键结构是否被裁，包装看角色与文字的层级，系列看各角色是否能从同一规则推导并独立辨认。

| 看到的问题 | 从哪里改 |
| --- | --- |
| 海报有名有景才认得出 | 主体轮廓、连接关系和代表品类的关键部件 |
| 认得出原型，像通用素材 | 单看轮廓是否有性格，记忆点能否承担结构和角色动作 |
| 特征很多，视线不知道往哪看 | 找最大明暗反差与最密集的细节。合并次要色块或纹样，把反差留给有意义的部位 |
| 造型成立，表情还是像素材库 | 固定脸的外轮廓，改变五官的占比和位置。连同姿态判断情绪方向 |
| 立体感全靠高光 | 灰模的厚度、转折、遮挡和接触阴影 |
| 发灰、泛黄、油亮或像随机拼材质 | 在中性光下查固有色和明度，再查粗糙度、反射、光源及局部纹理 |
| 侧背面像换了角色 | 对齐高度、体积、接点和遮挡，核对可见性，再处理表面 |

选稿时写清采用哪一款、哪处可见差异支持首要目标，以及仍有什么容易误读。需要检验观众理解时，按目标用开放问题收集第一反应，如「你觉得它是什么」「它刚才做了什么」「哪两个像同一家族」。有实际反馈时记录回答及对应稿件。仅有设计自检时，把误读写成待验证的判断。需要回查教学证据时，读取 [原帖案例与迁移方法](references/case-notes.md)。
