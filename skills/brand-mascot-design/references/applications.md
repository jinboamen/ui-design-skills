# 系列与品牌应用

## 区分系列、变装和单品换材质

用同一行列出角色共有的形体关系、各自的主题来源、可变化的部位和使用动作。系列可以靠同一线条粗细和表情语法统一，也可以靠世界观和使用场景统一。把成员等高排列后先看体型或五官。若去掉颜色就看不出差别，在其中一两个成员上增加有主题依据的形体差异。人数按角色之间真正需要发生的事来定，避免只为填满画面加角色。 [葱鸡](https://www.xiaohongshu.com/explore/69c22c7d000000002301e678) [系列差异](https://www.xiaohongshu.com/explore/6981a518000000001a030992)

换装要同时保留角色自身和这次主题的识别。先各选一个主特征，测试从正面、四分之三侧面和缩略图还能否看见。帽檐与耳、袖口与手、领口与脸需要真正接合。只有颜色或衣纹变化的同一个造型可作为换色或换材质款，系列角色还应有能独立读出的差异。 [变装识别对照](https://www.xiaohongshu.com/explore/69cf73d0000000002800bf92)

## 让动作和构图服务同一个用途

先确认观众第一眼应该看到角色的哪一处。图鉴平排时优先让每个成员看得清。群像用前后和大小差突出主角色，允许有依据的遮挡。故事场景画出触发物、角色动作和后果，画面大小、色差与动线都指向这件事。用同一角色测试两种构图时，保留角色比例与行为，只调整景别、背景和元素位置。动作不足时先改受力和镜头，杂物太多时先合并背景色块。 [场景构成对照](https://www.xiaohongshu.com/explore/69c5e284000000001f00225c) [系列陈列](https://www.xiaohongshu.com/explore/69c48e8100000000230179d3)

动效稿可以先用固定镜头核对微动、轮廓和起止帧，有镜头叙事时为每段写清主体动作、相机方向及景别。每次切换后确认面部、主形和材料仍是同一个角色。静态视角换了，大小和接点仍应与标准像相符。 [动效对照](https://www.xiaohongshu.com/explore/6afd764f00000000240333fb)

## 把识别特征带到实际载体

| 载体 | 优先试什么 |
| --- | --- |
| 标志、头像 | 选一处能代表品类与角色的组合，例如面包外框和熊耳。按实际最小尺寸试纯色版本，比较哪处一删就不认得，清掉挤在一起的细线 |
| 贴纸、徽章 | 检查角色外围、字与底形的空间，刀线和边距按实际制作要求。灵活使用完整角色、单一特征或带文字的版本 |
| 主海报与包装 | 小构图先比较角色、产品、标题三者的位置和大小。正面大图给第一识别点，小面继续使用放得下的特征和配色。按同一规格核对不同包装的裁切 |
| 商品样机 | 每件先检查贴图如何随表面转折，颜色和结构有没有被质感吞掉，再组合展示。规范页和效果图分别提供可量的关系及实际观看效果 |

过程页优先展示会改变方向的比较，例如原型和剪影、原稿和改稿、灰模和材质。一个应用再展示局部即可解释细节。用最终预览核对包装、海报和微型标记是否仍由同一角色体系推出。 [面包熊标志](https://www.xiaohongshu.com/explore/6a6c6af200000000280091df) [夜猫台球](https://www.xiaohongshu.com/explore/69d5bcd4000000001a034951) [作品集展示](https://www.xiaohongshu.com/explore/68d3b7d600000000130184a0)
