# 三维造型、材质与灯光

用于要三维风格稿、潮玩渲染或修正质感的任务。把「想做得有质感」改写成可检查的形体、表面和灯光要求。

## 从线稿到灰模

1. **为每个有识别作用的部分确定截面和厚度。** 按主块、附属块、小细节整理。示意起来像一片色块的脸，要明确它是贴印、凹进去还是凸出来。造型语言决定哪些边是饱满的圆弧，哪些边只做轻微倒角以保留利落感。可见的交接处明确穿插、压接或留缝。灰模优先检查外轮廓、体块层次和转面。
2. **选主视图，再查易错视角。** 首张用最能同时看清脸、主块厚度和记忆点的角度。侧面、背面按标准像对齐地面、眼位、接点和最大的体块，跟踪关键部件的朝向。转到背面时检查孔、正面图案、五官等是否应隐藏。先列出可见性再出图，避免 AI 把正面细节复制到背面。精确三视图优先由同一结构稿或模型投影，再检查轴线和尺寸。

## 给材料分工

给每种材质写四项信息：所在部位、希望读到的触感、可见反射特征、纹理尺度。一般先选一种主材质，再用少量对照材质来强调结构。按媒介增减，区别玩具、软质物、釉面、金属等质地的证据。

| 可选视觉方向 | 要看得到的现象 | 容易失控的地方 |
| --- | --- | --- |
| 哑光搪胶、软胶潮玩 | 面转有宽而软的亮带，阴影过渡连续，表面整体平整，局部如眼珠可更清晰反光 | 硬白高光覆盖全身，看起来像涂油 |
| 粉哑黏土或涂层 | 高光弱、厚度靠面转、接缝和落地阴影，近看才有轻微颗粒 | 粗噪点一缩小就像脏污，体块边缘也随之模糊 |
| 釉面和局部透明件 | 主体高光有明确来源，较亮的反射集中在釉面或透明件，透明件的边缘与厚度可读 | 亮膜把眼嘴和颜色反差吃掉，不同部件看起来用了同一种表面 |
| 毛绒、织物 | 短毛或织纹与体块成比例，受光边缘稍柔，接缝与受力相关 | 满身纤维盖住角色剪影，小尺寸下表情和材质一起消失 |
| 局部金属、硬塑 | 硬面有清楚的边缘过渡。金属反射周围明暗，硬塑保留其固有色。限定到镜框、工具、底座等需要区别的部件 | 用全身的镜面反射代替体块，逆光时脸部和主结构消失 |

这些方向是实施示例。材质服务性格和载体，可根据项目做其他取舍。在渲染工具里，粗糙度影响反射的扩散与清晰度，金属和透明表面有独立的着色参数。先根据画面目标测试，数值随渲染器、着色器、灯光和体块调整。需要具体参数时以实际工具的文档为准。[Blender Principled BSDF 文档](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html)

## 先选三维风格，再定表面做法

三维风格同时决定大形、转折、细节层级、表面和布光。比较风格时固定品类识别点与角色自己的记忆点，允许改变圆角、厚度、关节的表现和表面分区。同一结构的材质样张则固定机位、色值、背景与灯光，每轮只改一个表面变量。按当前问题选择哪种比较。

| 风格方向 | 造型、色彩和材质怎样配合 |
| --- | --- |
| 现代简约软胶 | 大体块饱满，转折少。主体用细哑表面和连贯的软亮带，重点部位留一道更清楚的反光。靠体块接触与倒角说明深度，保持脸部干净 |
| 轻质感插画或拟三维 | 结构仍以清楚的平面分区呈现。区分固有色、面转、投影、少量轮廓光。阴影先跟随遮挡关系，渐变只用在能解释体积的位置 |
| 机能与工业感 | 大轮廓保留直面、硬边和有功能的连接。只在机械部件使用窄亮边、细密防滑纹或局部金属反光。接触皮肤、表情或大面积壳体可以保持柔哑 |
| 手办陈列 | 用灰模查雕塑和接点。白模看浅色面转和边缘，背景与边缘之间留足明度差。透明版本看折射、厚度和轮廓，展示时避免用高光掩盖识别点 |

相机猴提供了一个可迁移的分区例子。机身、四肢保持柔哑，深色镜头环用稍硬的转折、细密的防滑纹和窄金属边区分工业件。把纹理精度留给需要说明用途的部位。到了头像尺寸，镜头的环形结构仍应清楚，外环的细纹可自然合并。[相机猴草图与材质示例](https://www.xiaohongshu.com/explore/6ae0760d000000002802db58)

水晶猫和潮玩「玩界」示范了两种分区。前者用饱满的猫形保留角色，晶感在局部表达原型。后者让低反射的帽和脸撑住表情，把更明显的反光交给相机和滑板。对同一角色比较玻璃、金属、粗糙或光亮变体时，先检查原色版本能否靠剪影独立成立，再并排确认材料变化有没有盖住主记忆点。 [水晶猫](https://www.xiaohongshu.com/explore/6af58f27000000002b030dfd) [玩界](https://www.xiaohongshu.com/explore/69e1cf35000000002003ae73)

做中性材质样张时，可保留一张灰模、一张主材质和一张有针对性的变体。诊断油亮时先锁灯光，对比反射覆盖范围、亮带边缘和强度。若白色仍偏黄，用中性背景和固有色样色分查背景反射、灯光色温和表面颜色。若暗部全灰且没有接触感，先保住关键遮挡和明暗，不用增加纹理补救。同一材质跨视图会随角度改变反光位置，材料的底色和视觉粗细应一致。

按故障分别做对照。食品原型颜色不准时，选一处受中性光的中间调直接与产品对比。亮带太尖或多个部位同样油亮时，先固定色值，用同一光源单独试粗糙度和涂层，再看光源形状。眼部的凸起或贴片边缘产生多余高光时，检查那一处究竟需要凹槽、实物件还是贴面。局部修完后看整套动作的眼形和受光是否仍一致。 [原型色和反光对照](https://www.xiaohongshu.com/explore/6a7ae9d5000000002202e22b) [BOTA 三维修稿](https://www.xiaohongshu.com/explore/6aca17e3000000000200c825)

## 先建立光照，再做修饰

1. 固定中性背景、镜头和光向做对照。用主光说明头身和附属块的转面，控制补光让暗部有体积。连接处留接触阴影，脚下有明确落地感。大面积柔光源通常给出更柔和的阴影过渡。[Blender 灯光文档](https://docs.blender.org/manual/en/latest/render/lights/light_object.html)
2. 在同造型、同灯光和同机位下换材质检查。比较高光宽窄、峰值、色块层次、细节可读性、纹理尺度。轮廓光只用于需要分开的局部。先确认原有色块在中性光下仍能辨认，再试风格化环境色。
3. 修图按成因处理。发灰时先比较灰阶和固有色，偏黄时找是光源或反射染色还是贴图问题。油亮时检查高光强度、反射是否过于尖锐或铺满、是否有多余涂层效果。层次看不清时回到体块、遮挡和光源，仍需纹理时只加在有材料依据的部位。

## 可复用的生成约束

提示词依次写角色参照、固定体块与连接、当前视角和应见部位、主辅材质的可见证据、光向及接触阴影、这次要求变化的一项。先验一张，局部问题按单变量做修正图。多视图至少比对主块厚度、部件数、接点位置、色块跨面与反光一致性。交付一张三维风格图时称为渲染或效果图。可旋转的模型、贴图或工程文件按需求单独创建和验证。

交付正、侧、背面规范图时，以统一底线和标尺呈现，至少核对头顶、眼位、附件轴线和脚底。四分之三视角可另作展示图，用于解释前后体块。AI 图片上的网格线、软件界面和材质预览只能作为视觉信息，网格拓扑、可旋转性和可制造性需从实际模型检查。
