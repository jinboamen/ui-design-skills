# 创意、体型与表情的推导

用于新设计、弱记忆点改稿、角色风格探索或从一个角色建立系列。先选最需要解决的段落。

## 先决定为什么这样长

从产品或行业各挑能画出来的线索，例如外形、横截面、开合或生长动作、制作工具、使用时机。再从角色一侧找姿态、器官和行为。优先考虑两者的形状、功能或动作是否能接在同一个部位。若两项只能通过旁边放一个道具联系起来，尝试重新确定主原型或退回单原型设计。

| 可比较的造型路径 | 草图上看什么 |
| --- | --- |
| 放大原型最有辨识力的局部 | 关键特征占据哪段轮廓，能否自然变成发力部位或表情 |
| 用行业物件替换头、躯干或某个器官 | 结构如何接合，第一眼读到的是不是项目想要的主题 |
| 用产品的典型动作改写整体形态 | 动作能否改变轮廓，例如弯、卷、伸、缩、开合，停下后还认得出来 |
| 让次要线索通过局部材质出现 | 当两种外形强行叠在一起会损害剪影时，保留识别更强的大形。把另一条线索落在一处有功能的部件上，并比较去掉这层材质后主体是否仍成立 |

这些是可比较的路径。组合题材并非所有项目的必选项。主创意已经清楚时，试着删掉最抢眼的装饰。若角色还显普通，优先改高宽比、上重下轻或下重上轻、哪里宽哪里窄。记录淘汰理由，例如「脸像普通熊，产品特征只在衣服上」或「第一眼看到帽子，主体的招牌形态反而被遮掉」。

找不准识别点时，做一张只变一个部件的对照。固定头身、五官和颜色，分别替换耳朵、尾巴或产品部件。再去掉五官，把图缩到实际最小尺寸。行李箱如果少了拉杆便只像普通动物，补的是拉杆和机身的连接。南瓜猫缩小后如果瓜瓣和胡须糊在一起，保留叶形、橙色和外边，删多余的线。必要时分别核对物种、品类和专属于品牌的特征。

## 用比例画出性格和视觉顺序

选稿问题要随题目改变。例：为折叠台灯做角色，比较灯罩与支臂在直立、俯身时是否都能读成台灯。为失物招领服务做角色，可以画它发现遗失物后如何保管、如何交还，比较哪一款更容易看懂它在帮助谁。为已有角色做节日动作，则把头形、眼位和四肢接点与标准像对齐，再检视动作是否有新意。

- 以默认站姿先定最高点、最宽处、承重处。固定其中两项，改变另一项，能看出决定性格的是哪处。头身一体的造型看主块饱满度、收尖处和附肢大小。分体角色才需要用头与身体的高度比比较。约 1:0.5、1:1、1:2 可用作草图试点，根据首要使用动作和用途调整。记录是否算上耳、帽和底座，便于多视图对齐。
- 同尺寸并排看剪影。选择一处大的形态反差，例如宽躯干配很小的脚、窄上身配外扩底部。需要让角色奔跑、抱物时，按动作留出具体关节和空间。适合漂浮、弹跳或开合的角色可以省一类肢体。
- 比较拉长或缩短时，同时看量感和重心。黑兔案例里，头变小、身体拉长并拉直可以显得冷酷有力。把同一变化继续推远，躯干和四肢都变细，读感就转成了纤弱。按实际剪影停在合适的程度。不能只用一个头身数值判断性格。
- 看完剪影，再把内部铺成明、灰、暗三档。不需要在每个部位平均用强调色。检查由上到下阅读时，有没有大色块完整、脸与身体互相分开、次要纹理让位。尾巴、围巾、鞋等抢眼时，可以合入相邻色块，仅保留解释接点的明暗差。

## 给那张脸一套变化规则

先选一个五官承担主要表达，例如眼睛负责视线和态度，嘴负责爆发动作。按原型和性格选择需要的器官，允许省鼻、眉或嘴。固定原型器官、五官所在的体块和中性表情，再在同一头形上试眼距、眼位高低、眉眼距离、嘴的开合与宽度。保留一组辨识度最强的变化，记录「动什么」和「什么位置固定」。

| 表情试验 | 看哪里 |
| --- | --- |
| 中性、轻微、强烈的同一种情绪 | 从小范围眼睑和视线变化，逐步到口形、脸颊或身体压缩。比较情绪强度是否递进 |
| 同等强度的两种不同情绪 | 去掉色块和符号，检查眼睑角度、视线、嘴形和躯干是收缩还是展开，有没有画成同一个大嘴 |
| 同一动作的两种姿态 | 道具接触、重心和视线要同向。尝试左右手脚各负担不同任务 |

色彩和符号可以读成情绪的加重手段。先让面部和肢体在没有文字时成立。做成贴纸、缩略图或三维版本后再检视强弱两档，避免把脸挤进装饰密集的区域。

只有眼睛的角色可以先测试眼形的开合、弧度、倾角和视线。屏幕或面罩限定了五官区域时，固定外框与眼睛的落点范围。表情仍有两种读成一样时，先改眼形的拓扑或方向，必要时才在强表情加嘴。判读时把眼形放回整张脸和同一个场景里，一条线或一种倾角可以有多种读法。

## 用行为和画面测试角色

给角色一次符合身份的具体事件，例如产品在场、职业任务、性格与环境发生冲突或从真实历史线索长出的日常行为。写清触发、动作、结果。拿掉角色后如果场景和道具能自己完整讲完这件事，改成由角色的独特结构或习惯触发结果。

做成系列时，先在同一基线上排一组无色剪影，给每个角色一个清晰的高度、宽度和重心位置。角色间可保留共同的五官语法、造型繁简、材质、色彩调性或世界观，再用体型、原型轮廓及行为分工拉开差距。统一使用试色、布光与裁切条件，检查角色单独出现会不会被认成另一个成员。

动作僵硬时，先查受力处。坐姿要沿承重弯出明确的背部弧线，趴姿要看躯干压缩和接触点，倾身时要看重心和支撑的关系。比较一组动作时，允许角色在统一画幅内趴低、跃高或转背，保持标准像的肢体接点与基准比例。若单张为了填满画幅把手脚拉长，回到姿态本身修正。

夸张有两条路径。先画动作本身，区分肩髋倾斜、弧线、重心、接触和手脚先后。骨架有说服力，再试俯视、仰视或近大远小。还有必要时从动过的部位画有方向的拖影或速度线。做表情延展时，先让耳、冠、尾等可动部位在大形内配合表情。允许一边变化得更多，检查它是否还像同一个角色。

在系列和换材质时分别记录家族常量和每个成员的识别线索。比如葱鸡的眼罩、喙和短脚构成共有关系，冠部、体形、颜色和表面可按不同原型调整。系列图去色检查剪影，再用单色或金属版检查材质改变后还有哪些身份特征。

## 用上轮失败的图做回归检查

「浇水壶加通用脸、四肢和黄靴」在原型检查里可以认出品类。要通过创意比较，还需要一张结构明显不同的替代草图，让喷头或提手不仅是壶的零件，还能决定角色特有的动作和性格。若三维方案仅给同一个平面形象加亮边，先退回体块图，再做材质样张。这个例子用于审稿，现有图片仍可用于反面核对。
